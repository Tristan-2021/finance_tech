# feature_guardian

보호자 모드 화면 패키지입니다 (기획서 5.8).

- **위험 근거 요약 (`incident_summary_sheet.dart`)**: 진행 중인 사건의 문자, 통화 징후, 금융 행동, 확인 질문 답, 판정, 보류, 보호자 조치를 시간순으로 보여 줍니다. 원문이 아니라 서버가 사건에 남긴 요약만 쓰며, 보류 카드(`RequestCard`)에서도 한 번에 열 수 있습니다.
- **위험 기록 (`guardian_alerts_view.dart`, `guardian_home_view.dart`)**: 지난 사건 목록과, 사건을 눌렀을 때 열리는 시간순 요약 상세 시트를 제공합니다.
- **보류·주의 모드·가족 관리 (`guardian_home_view.dart`, `guardian_manage_view.dart`, `request_card.dart`)**: 보류 해제·연장, 주의 모드 해제, 앱 안 가족 통화, 가족 상태·한도·안심 모드 관리, 원격 동결·해제를 제공합니다.
- **QR·코드 연결 및 동의 (`pairing_sheet.dart`)**: 5단계 흐름("1 / 5" ~ "5 / 5")으로 보호자 기기 QR·코드 표시, 어르신 기기 QR 스캔 또는 연결 코드 직접 입력, 보호자가 보게 되는 정보(위험 알림, 위험 근거 요약, 보류 상태) 안내와 `[동의]` 제출을 제공합니다.

## 추가한 패키지

- `qr_flutter`: 보호자 기기에서 연결 코드 값을 QR 코드 이미지로 렌더링해 보여 주기 위해 추가했습니다.
- `mobile_scanner`: 어르신 기기에서 카메라로 보호자 QR 코드를 읽기 위해 추가했습니다(카메라가 없는 에뮬레이터를 위해 같은 코드 값을 직접 입력하는 경로를 함께 둡니다).
