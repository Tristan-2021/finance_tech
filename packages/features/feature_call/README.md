# feature_call

휴대폰 통화 앱을 재현한 화면과 시연 상대 화면 패키지입니다 (기획서 3절, 5.3, 8절).

- **통화 화면 (`CallSheet`)**: 발신, 수신, 통화 중, 종료 화면을 표시합니다.
- **WebRTC 음성 연결 (`rtc_session.dart`)**: `flutter_webrtc`로 외부 STUN·TURN 없이(`iceServers: []`) 음성(`{'audio': true, 'video': false}`)만 연결하며, 연결 신호(offer / answer / ICE)는 `/api/v1/ws`로 주고받습니다.
- **4초 조각 녹음 (`chunk_recorder.dart`)**: 분석 대상 통화(어르신·아이 ↔ 시연 상대)에서만 `record` 패키지로 4초마다 마이크 음성을 WAV로 녹음해 서버로 올립니다. 녹음이 실패해도 통화는 끊기지 않고 화면에 `"음성 분석을 쓸 수 없어요"`를 표시합니다.
- **통화 중 경고**: 사기 징후가 감지되면 깜박이지 않는 큰 경고 카드와 쉬운 설명 한 줄, 진동·경고음(3초 미만, 한 번), `[통화 끊기]` 버튼을 표시합니다.
- **시연 상대 화면 (`CounterpartSheet`)**: 은행 기능이 없는 시연 전용 화면으로, 시연 문자 보내기(사칭·정상), 걸려 온 전화 받기, 통화 대본 표시와 `"음성인식 없이 문장을 보냅니다"` 대본 문장 보내기를 제공합니다.
