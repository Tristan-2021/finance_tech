# feature_sms

휴대폰 문자 앱을 재현한 화면 패키지입니다 (기획서 5.2, 5.5).

- 발신 번호별 대화 목록(`SmsConversation`)과 시간순 말풍선(`SmsBubble`)을 표시합니다.
- 서버가 위험(`danger`)으로 판정한 문자에는 경고 배지(색 + 글자 + 아이콘), 쉬운 설명, 판정 근거를 함께 보여 주고, 정상(`low`) 문자에는 경고를 붙이지 않습니다.
- 문자 속 링크는 어떤 경우에도 외부로 열지 않으며, 누르면 `"이 링크를 열지 않았어요"`와 차단 이유를 보여 주는 차단 화면(`BlockedLinkView`)이 뜹니다.
- 문자 속 전화번호는 `onTapPhone` 콜백이 연결되기 전(4단계 통화 화면 구현 전)까지 누를 수 없는 일반 글자로 표시합니다.
