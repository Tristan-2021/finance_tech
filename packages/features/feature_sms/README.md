# feature_sms

iOS 메시지 앱 모양을 흉내 낸 휴대폰 문자 화면 패키지입니다 (기획서 5.2, 5.5).

- 최신순 대화 목록(`메시지`, `SmsSheet`)과 시간순 받은 문자 말풍선(`SmsBubble`)을 표시하며, 위험·주의 대화에는 보낸 사람 옆에 아이콘 + `"위험"`/`"주의"` 배지를 붙입니다.
- 서버가 위험(`danger`)·주의(`caution`)로 판정한 문자는 말풍선 아래 알림 띠 카드(`"사기 의심 문자"` / `"주의가 필요한 문자"`, 쉬운 설명, 판정 근거, `[사기 신고·도움]`)를 붙이고, 정상(`low`) 문자에는 경고를 붙이지 않습니다.
- 문자 속 링크와 전화번호는 말풍선 안에서 파란 밑줄 글자로 보이며, 말풍선 바로 아래(경고 띠 위)에 높이 `57dp` 이상의 iMessage 미리보기 줄(`호스트 / 링크`, `전화번호 / 전화 걸기`)을 함께 둡니다(`전화 걸기` 줄은 `onTapPhone`이 주어졌을 때만 표시, 링크가 없는 정상 문자에는 줄이 없음).
- 링크는 말풍선 안 글자나 링크 미리보기 줄 어느 쪽을 눌러도 외부로 열지 않고 `"이 링크를 열지 않았어요"` 차단 화면(`BlockedLinkView`)이 뜨며, 번호·미리보기 번호 줄·대화 상단 전화 버튼은 `packages/app`의 전화 앱(`feature_call`)으로 연결합니다.
