# 핑거벨 지침 적용표

이 문서는 **핑거벨(FingerBell)** 시연용 앱 묶음(`핑거벨` · `핑거벨 문자` · `핑거벨 전화`)에 아래 세 지침의 원칙을 어떻게 반영했는지 실제 구현 코드와 테스트 기준으로 정리한 표입니다.

- 핑거벨은 가상 계좌·가상 상품을 쓰는 시연 앱으로, **지침의 원칙을 적용했다**는 점을 정리한 것이며 공식 인증을 받거나 심사를 통과한 것은 아닙니다.
- 「핑거벨 기획서」 7.4절에 따라 금융용어사전 전체, 챗봇 상담, 투자성 상품 설명, 영상 자막·수화, 본인 인증은 구현 범위에서 뺐습니다.
- KS X 3253의 실제 사용자 평가는 에이전트가 대신할 수 없으므로, 발표 전 어르신 한 명 이상이 직접 사용해 보는 확인을 권한다.
